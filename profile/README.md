### What Nervenet does

Nervenet brings tools, files and subagents together so a conversation turns into work you can review.

| | |
|---|---|
| 🧠 **Any model** | OpenAI, Anthropic, local servers like Ollama or LM Studio, or any OpenAI-compatible API. Pick a model per chat. |
| 📁 **Works in your folder** | Reads files, edits code, runs commands and researches the web, right where your project lives. |
| 🤝 **Subagents** | Hands parts of a big job to focused helpers and brings their reports back to your main chat. |
| ✅ **You stay in control** | Asks before risky steps. Approvals stay with you, and your keys stay yours. |
| ⏰ **Scheduled chats** | Keeps tasks moving on a schedule while your computer stays on. |
| 💬 **Messaging channels** | Reach your agent from WhatsApp or Telegram and approve steps from your phone. |
| 🧩 **Skills, connectors & memory** | Extend what it can do and let it remember what matters. |
| 🎨 **Studio** | Opens results in Studio so you can see the work, not just read about it. |

### Get started

1. Download the latest Windows preview from **[Releases](https://github.com/MuhammadNoman76/Nervenet-app/releases)**.
2. Add your model provider and pick a project folder.
3. Give it a job.

Learn more at **[nervenet.app](https://www.nervenet.app)** · [How subagents work](https://www.nervenet.app/subagents/) · [Channels guide](https://www.nervenet.app/channels/)
